## PTT Volleyball 板

標題：[分享] TVL 球迷自製數據站：賽事、球隊與球員數據

各位板友好，我是小易。

看企業排球時，常想把兩隊近況和球員表現放在一起看，所以做了這個 TVL 數據站，分享給同樣喜歡企排的大家。

站台網址：https://oldyi317.github.io/TVL-Analysis/

目前可以查看：

- 賽事日期、時間、場館、對戰與各局得分。
- 各賽季、男子組與女子組的球隊戰績及技術數據。
- 球員的單場數據、逐場趨勢與進階數據，搭配週登錄及主要位置查看表現。
- 未開打賽事的賽前勝率，作為看球前的參考。

關於賽前勝率，站上的說明是：

依兩隊近 3 至 5 場技術統計推估，未考慮對手強度與主客場；開季初以上季末近況為準。交叉驗證 F1 約 0.61，僅供參考。

資料來源為 TVL 企業排球聯賽官網（https://tvl.ctvba.org.tw/）；早期賽季的單場數據保留自官網連結的技術統計系統。站台每日更新，實際內容仍以來源公布的資料為準。

這是球迷自製的非官方網站，與聯賽及各球隊無關。隊徽與球隊名稱的商標屬各球隊與聯賽所有。

程式碼以 MIT 授權公開，作者：小易。
原始碼與授權：https://github.com/oldyi317/TVL-Analysis

如果發現數據有誤、頁面異常，或有功能建議，歡迎透過 GitHub Issues 回報，附上頁面連結、賽季、組別及遇到的狀況，方便查核：
https://github.com/oldyi317/TVL-Analysis/issues

希望這個小工具能讓大家看企排時多一點樂趣，也歡迎分享使用心得！

小易
