# 球員只保留公開欄位，生日從爬蟲到頁面全面移除

repo 與 GitHub Pages 都是公開的，`data/db/tvl_database.db` 又刻意 commit 進 git，所以資料庫裡有什麼就等於對外公開什麼。盤點發現 `players.dob` 有 144 筆完整生日（含 2 名未成年球員），來自官網舊版球員卡；官網現行球隊頁只顯示身高與體重，已不再公開生日。生日對球迷看球不是必要資訊，卻是身分辨識的關鍵欄位。

決定：以 CONTEXT.md「公開欄位」為界——姓名、身高、體重、位置、背號保留；生日全面移除：爬蟲不再解析日期欄、資料庫該欄清空、匯出器與球員頁不輸出。「只存不顯示」不成立，因為資料庫本身就是公開物。年齡或出生年同樣不顯示，不做折衷。

## Consequences

- 資料品質原則「不插補、不竄改」針對比賽數據；刪除身分欄位不在其範圍內。
- 日後若要加任何新的球員資料欄位，先對照「公開欄位」定義，官網未公開的不抓。
- `players.dob` 欄位從 schema 與已 commit 的資料庫一併移除，不留空欄，避免載入器的「NULL 不覆蓋舊值」邏輯日後把值填回來。
