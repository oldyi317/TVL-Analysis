# 設計規範（web/ 靜態站）

> 對應 issue #6。token 的唯一來源是 `web/src/app.css`；本檔說明依據與使用規則。
> 樣式指南頁：`/TVL-Analysis/styleguide/`（用真實球隊資料渲染，簽核用）。

## 一、要解決的事

舊站兩個毛病：太陽春、字太小。這份規範用三件事回應：

1. **數字當主角**：比分、勝場、積分、攻擊得分用專屬的數字字級（24 / 36 / 52px），粗體、等寬數字。頁面上最大的東西永遠是球迷要找的那個數字。
2. **隊色是唯一的彩色**：中性底、黑白字；只有隊標、隊色條、隊色文字帶顏色。十二隊的顏色就是辨識系統，不另設品牌色。
3. **正文 16px 起跳**：手機上不再有 12、13px 的正文。14px 只給日期、場館、欄位名這類附註。

視覺參照中華職棒 app：手機優先、卡片式、大數字、隊色識別、淺深雙模式。但不抄它的紅色品牌調，也不用陰影堆卡片——卡片靠「表面色對背景色」加一條 1px 分隔線成形。

## 二、色彩

### 中性色（淺色 / 深色）

| token | 用途 | 淺色 | 深色 |
|---|---|---|---|
| `--bg` | 頁面底 | #f2f3f5 | #121417 |
| `--surface` | 卡片、表格、頁首 | #ffffff | #1c1f23 |
| `--text` | 正文、數字 | #15171a | #eceef0 |
| `--text-muted` | 附註、敗方、非當前 | #5b6168 | #a3a9b1 |
| `--line` | 分隔線、外框 | #c8ccd2 | #3a4048 |
| `--accent` / `--on-accent` | 當前組別、主要按鈕 | #15171a / #ffffff | #eceef0 / #121417 |

中性色帶一點冷灰（體育館、水泥地），不用米白暖底。深色模式表面比背景亮一階，卡片才浮得出來。

中性色刻意用角色命名（底、表面、文字、附註、線），不另給 gray-1 到 gray-9 的數字階：元件只能挑角色，不能自己挑一個灰，雙模式才不會各自漂移。要新的灰就新增角色 token，並補進 `tokens.test.ts` 的配對。

### 語意色

| token | 意義 | 淺色 | 深色 |
|---|---|---|---|
| `--win` | 勝 | #15803d | #4ade80 |
| `--loss` | 敗 | #b91c1c | #f87171 |
| `--warn` | 警示文字 | #b45309 | #fbbf24 |
| `--warn-tint` / `--warn-ink` | 警示底 / 警示底上的字 | #fef3c7 / #78350f | #3a2a0a / #fde68a |

勝敗**不能只靠顏色**：勝方用 `--text` 粗體，敗方用 `--text-muted` 一般粗細；`--win`/`--loss` 只是加強，拿掉顏色仍看得出誰贏。

### 隊色

隊色存在 DB `teams.color`，單一來源。每隊衍生三個用途，由 `web/src/lib/color.ts` 計算，不另外手填：

| 用途 | 怎麼來 | 規則 |
|---|---|---|
| 填色 `fill` | 原始隊色 | 隊標圓形的底、卡片隊色條 |
| 填色上的字 `onFill` | `textColorOn()` | 黑或白，對隊色 ≥ 4.5:1 |
| 文字色 `ink` | `inkOn(color, surface)` | 保留色相，只調明度，直到對當前模式的 `--surface` ≥ 4.5:1 |

淺色模式下 #999999、#e6ab02、#66a61e 這類淺色直接當文字會不及格，所以隊色**只能以 `ink` 變體當文字**；`fill` 永遠只當底色。深色模式下 #666666、#984ea3 這類暗色的 `fill` 對表面只有約 3:1，隊標靠圓形與簡稱辨識，不靠底色。

JS 端需要色值的只有兩處：`color.ts` 的 `SURFACE`（算隊色變體）與 `chart/theme.ts`（ECharts 不吃 CSS 變數）。兩處都由 `tokens.test.ts` 對 `app.css` 核對，其餘程式一律用 CSS 變數。

### 對比度

兩種模式所有「文字 × 背景」組合達 WCAG AA 4.5:1，由 `web/src/lib/tokens.test.ts` 直接解析 `app.css` 驗證；隊色三種變體由 `color.test.ts` 對全部十二隊驗證。改 token 必須讓這兩個測試過。

### 淺深模式

跟隨系統：`color-scheme: light dark` 加 `@media (prefers-color-scheme: dark)` 覆寫同一組 token；元件只用 token，不寫死顏色，就自動支援雙模式。不做手動切換開關。`<meta name="theme-color">` 兩種模式各一個，對應 `--surface`。

## 三、字級

字型：系統字型堆疊（Noto Sans TC / PingFang TC / Microsoft JhengHei），不載網路字型。全站開 `tabular-nums`，數字欄對得齊。

| token | px | 用途 |
|---|---|---|
| `--text-sm` | 14 | 附註：日期、場館、欄位名、頁首「非官方」註記。**不當正文，也不給可點的文字** |
| `--text-md` | 16 | 正文、列表、表格文字、按鈕 |
| `--text-lg` | 18 | 區塊標題 h2、隊名（卡片上） |
| `--text-xl` | 22 | 頁標題 h1 |
| `--num-md` | 24 | 表格數字、逐局比分、球員背號 |
| `--num-lg` | 36 | 賽事卡的局數比 |
| `--num-xl` | 52 | 球員頁三大項的大數字 |

數字字級一律粗體 800（`--weight-num`）、行高 1。文字行高 1.5。h1 700、h2 700。

例外：隊標與背號圓內的字是裝飾（`aria-hidden`，名稱由旁邊文字承載），字級跟著圓形直徑走（sm 10px / md 12px / lg 16px），不受 16px 下限約束；逐局比分在手機上縮到 `min(24px, 4.8vw)`，讓五局排得進一行。

## 四、間距與圓角

4px 基準：`--space-1` 4、`-2` 8、`-3` 12、`-4` 16、`-5` 24、`-6` 32、`-7` 48。

- 頁面左右留白 `--space-4`（16px），內容最大寬 `--measure` 40rem 置中。
- 卡片內距 `--space-4`，卡片之間 `--space-3`，區塊之間 `--space-6`。
- 可點區最小高度 `--tap` 44px。

圓角三階：`--radius-sm` 8px（小標籤、按鈕）、`--radius-md` 16px（卡片）、`--radius-full`（隊標、球員背號圓）。不用陰影。

寬版斷點 48rem（768px）：戰績表在這之上自動展開完整欄位。

## 五、元件

元件放 `web/src/lib/components/`，只用 token，不寫死色值與 px。

| 元件 | 用途 | 規則 |
|---|---|---|
| `SiteHeader` | 頁首：站名、非官方註記、組別切換、賽季切換、頁面導覽 | 組別切換是兩格分段控制，當前格用 `--accent` 反白、高 44px、佔滿寬；賽季切換是一列小字 chip，放組別下方不搶眼；頁面導覽放最下 |
| `SiteNav` | 頁面導覽：首頁、賽事、戰績、球隊、球員 | `<nav aria-label="頁面">`，一列可橫向捲動、每項高 44px、粗體 muted；當前頁 `--accent` 反白、`aria-current="page"`（賽事詳情算在賽事下）；球員頁未建前與球隊同指球隊列表 |
| `MatchLink` | 包住 `MatchCard` 的整卡連結 | `<a class="card-link">`，hover 加陰影、active 微縮；首頁與賽事列表共用，卡片本身不含連結 |
| `TeamBadge` | 隊標記：隊色圓形加簡稱 | 三種尺寸 sm 32 / md 48 / lg 64px；`aria-hidden`，隊名由旁邊文字承載；三字內單行，四字拆 2+2（屏東／台電），更長在中英交界或中點斷兩行（臺北／Conti） |
| `MatchCard` | 賽事卡 | 第一列日期、星期、場館（sm, muted）；中間兩列各一隊：隊標 sm、隊名 lg、局數 `--num-lg`；勝方整列 `--text` 粗體，敗方 `--text-muted` 一般粗細（局數也是）；底部逐局比分一列 `--num-md`（手機縮字，見字級例外），贏的那局數字粗體；黃金決勝局另標「黃金決勝局」且不計入局數；未開打在局數位置顯示「未開打」（lg 粗體 muted），開賽時間有值時併入第一列日期後；可選 `stage` 在 meta 列右側以 sm 粗體顯示階段與週次（例：總決賽 第 19 週）；`showSets={false}` 隱藏逐局列（詳情頁下方另有逐局表時用） |
| `StandingsTable` | 戰績表列 | 手機精簡五欄：名次、隊伍、勝、敗、積分；每列可展開（按鈕 `aria-expanded`）看六種局數比分布、局數比、得失分比、近五場；≥48rem 自動展開成完整欄位，表格跳出 40rem 版心置中（最寬 60rem），再不夠才在卡片內橫向捲動；非現役球隊照常列出；名次與數字用 `--num-md` |
| `PlayerCard` | 球員卡 | 背號圓（`--num-md`、隊色 fill）加姓名（md 粗體）加位置（sm muted）；背號或位置缺值顯示「—」或省略，不編造 |
| `BigStat` | 大數字 | 標籤 sm muted 在上、數字 `--num-xl` 在下；三個並排 |
| `EmptyState` | 空資料提示 | 一句話說明沒有什麼，加一句能做什麼；置中、muted，不放插圖 |
| 賽事列表的月份列 | 吸附在頂部的月份跳轉 | 與賽季切換同款 chip，一列可橫向捲動；當前月份（捲動時自動更新）用 `--accent` 反白、`aria-current="location"`；每個月份一個 `<section>` 加 h2，`scroll-margin` 讓錨點跳轉不被月份列蓋住 |
| `DataNote` | 資料不完整註記 | `--warn-tint` 底、`--warn-ink` 字、正文字級，一行說清楚缺什麼（例：2024-25 女子組官網只收錄 8 場賽事） |

通用規則：

- 文案依 `CONTEXT.md` 詞彙（戰績、賽事、組別、賽季、週登錄），全繁體中文、句式口語。
- 缺值就顯示缺值，不插補、不隱藏。
- 動畫只用在回應操作的展開收合，且尊重 `prefers-reduced-motion`。
- 焦點外框 2px `--focus`，鍵盤可操作所有展開收合。

## 六、ECharts 主題

`web/src/lib/chart/theme.ts` 匯出 `chartTheme(mode)`，兩種模式各註冊一個主題；`Chart.svelte` 包裝元件在瀏覽器端掛載、跟著系統模式切換主題、跟著容器寬度 resize。

- 字級：軸標籤與圖例 14px、tooltip 16px；手機不縮小。
- 配色：軸線與格線用 `--line`、文字用 `--text-muted`、tooltip 底用 `--surface`。序列有隊伍語意時，呼叫端用 `teamPalette()` 的 `inkLight`/`inkDark` 自己設 series 顏色（主題沒有隊伍概念）；沒有隊伍語意時用主題的中性序列，每色對背景 ≥ 3:1（`tokens.test.ts` 守著）。
- tooltip `confine: true`，不會超出手機畫面；圖例放底部，`Chart.svelte` 會自動把 grid 底部留給圖例（`legend.show: false` 時不留）。
- 類別軸標籤不抽稀（`interval: 0`），類別多於手機放得下時由呼叫端自己縮減或改橫向長條。
- 只驗容器存在，不驗圖內容（父 spec 的接縫決定）。

## 七、怎麼驗

- `npm run test:unit`：token 對比度、隊色變體、局數計算。
- `npm run test:e2e`：手機視窗開樣式指南頁，無橫向捲動、正文 ≥ 16px、展開收合可用、深色模式背景改變。
- 使用者在手機實看樣式指南頁（淺、深各一次）並在 issue #6 留言簽核。

樣式指南頁會隨站台公開部署；球隊是真的，比分、戰績、球員與圖表數字都是示意資料，頁首已標明。
